# Coin Rush — Complete Game

`CoinRush.unity` is the finished workshop game: movement, coins, score, win/lose,
patrolling hazard, magnet power-up — everything the nine exercises build, in its final
form, with the reference `LevelValidator` and `BuildScript` in `Editor/`.

Use it to:
- demo the end state at the start of the lab ("this is what we build today"),
- compare against your own result after any exercise,
- run the closing-session demo and the mobile build.
